# Online Shopping System

A full-stack Online Shopping System that allows customers to browse products, manage their cart, and place orders. It also provides separate Admin and Staff dashboards for product and inventory management.

## Features

### User
- User registration and login
- Browse and view products
- View MRP, selling price, and discount
- Add products to cart
- Place orders

### Admin
- Admin dashboard
- Add, update, and delete products
- Manage product pricing and discounts
- Manage users and product details

### Staff
- Staff dashboard
- View product inventory
- Check available product quantities
- Manage stock information

## Technology Stack

- Frontend: React.js, JavaScript, HTML, CSS, Bootstrap
- Backend: Java, Spring Boot, Spring Security
- Database: MySQL
- Authentication: JWT

## Installation and Setup

1. Clone the repository:

   git clone https://github.com/SwarupChoudhary2024/miniD-mart.git

2. Open the project in VS Code.

3. Configure your MySQL database.

4. Update the database credentials in the backend configuration.

5. Install frontend dependencies:

   npm install

6. Start the frontend:

   npm run dev
  

7. Run the Spring Boot backend.
